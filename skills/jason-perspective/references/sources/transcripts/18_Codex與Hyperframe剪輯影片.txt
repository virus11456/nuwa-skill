它會重新安排開頭、整理字幕，再把照片、截圖和動畫接進去。像你看到的衣服被運費門檻擋住，貨箱經過倉庫運到海外，還有這種四張紙片隨著口播展開，這種效果都是它做出來的。
今天就把用 AI 做影片的粗剪、字幕、封面、素材、動畫，還有匯出這幾個環節走一遍，分享給大家。

我用的是 Codex 配合 GPT-6 Astra Ultra 模型，再加上 Hyperframe 來做。
GPT 用來理解我說了什麼，判斷內容怎麼安排，畫面怎麼表現；Codex 讓它能夠讀取本地檔案、調用工具，把這些想法做成工程；Hyperframe 負責預覽、編輯，還有匯出影片。
這些外掛的 GitHub 地址我也都放上來了，安裝都可以讓 AI 操作。

[00:59]
比如我把工具包和安裝文件給 Codex，直接說：「檢查這台電腦還缺什麼，幫我準備剪輯環境，需要權限的時候告訴我。」
裝好以後，先匯出一段帶中文字幕和聲音的測試影片，先驗證它真的是能匯出、能播放，中文和聲音都正常，再開始處理原片。

[01:16]
我們所有人剪口播影片的第一個環節，就是粗剪。像重複說兩遍、講錯以後重新來、多餘的口頭語，還有明顯的長停頓，Codex 都可以先找出來。
［原片示範重複句］就超過一百二十萬的商家。就超過一百二十萬的商家。
比如我那段「超過一百二十萬的商家」重複說了，它就會保留一遍。它會先列出建議刪除的位置和理由，我確認以後再剪。最後它刪掉了八處重複、空白、長停頓和多餘的口頭語。

[01:41]
Codex 粗剪還可以調整內容結構，甚至會做爆點前置，很有編導思維。比如它把我結尾的一句話搬到了開頭：「貨還是那盤貨，生意不必只做一盤。」
同時它只精簡了幾處過渡的地方，重要的觀點和兩個例子都保留了。很有意思，它不只是機械地刪除停頓，還可以理解哪句話更適合放在前面。

[02:00]
第二個環節是字幕。這次它發現我給的這份字幕順序有問題，字幕也會跟著新的剪輯順序重新調。比如影片順序有了變化，字幕也會跟著一起調。

[02:10]
第三個環節是配素材。它不是把我給的連結、圖片全部塞進畫面，而是找出當前口播對應的資訊塊，放大給觀眾看。
比如講海外客服，就突出客服那一行；講倉配服務，強調框會再移到對應的條目。像這種截圖進入時輕輕傾斜，帶一點紙片的層次，但是落穩以後就停下來的動畫效果，它也能做出來，讓人讀得更清楚。
像我的原片，因為人臉本來就離鏡頭比較近，所以這次它也沒有一直放大人臉，而是複雜的圖解就直接切成短暫的全螢幕，講判斷的時候再回到我的人臉上。

[02:41]
第四個環節是做動畫。我的經驗是，做好影片最好的方法，就是給它看參考。像我的 GitHub 工具包裡面就有參考影片，也可以提供自己喜歡的片子，讓它分析物件怎麼進入、移動、展開，以及怎麼跟人物畫面結合。
它還可以幫你做封面標題。直接說：「把這兩行標題添加。」它會自己判斷放在開頭的三秒，並且放在人物上方，不擋臉。

[03:02]
像這種兩分三十秒的影片，Codex 一輪剪輯差不多用了一個小時。我用的是 GPT-6 Astra Ultra 這個模型，是標準速度，差不多花了一美元的 Token。
會在 Hyperframe 的 Studio 裡面看到整個剪輯工程，和剪映這些剪輯工程類似：中間是畫面，下面是時間線，圖片和文字可以選中，也可以直接在上面手動調整。

[03:25]
確認後，也可以透過右上角匯出為本地的 MP4 成片。
當然也可以把這個過程生成 Skill，這樣下次剪輯就會更快，而且它還會知道你的剪輯風格和要求。
像我們已經把流程整理成 AI Video Edit 這個 Skill。下一條換選題、原片、素材還有參考，就可以繼續做，不用重新跟 AI 解釋溝通一遍。
